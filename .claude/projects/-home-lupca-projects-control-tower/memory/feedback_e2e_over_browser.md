Write E2E tests for verification instead of manually testing in the browser.

**Why:** Manual browser testing is slow and not reproducible. E2E tests provide automated, repeatable verification.

**How to apply:** When verifying frontend changes, prioritize writing Playwright/E2E tests over using browser automation tools for verification.
